# speckeep v1.0.1 — release notes (draft)

> Copy-paste target: GitHub Release body for tag `v1.0.1`.
> Merge `dev` → `master` first, then run the release workflow (`manual-release.yml`).

Stability and reachability release on top of v1.0.0. No breaking changes to
workflow artifacts — run `speckeep refresh .` once and `doctor` should be clean.

## Highlights

- **OpenCode is now skills-only.** The generated `.opencode/commands/spk-*.md`
  set was a redundant second entry point (OpenCode's `/` palette is built from
  `.opencode/commands/*` and explicitly skips `source === "skill"`). It is no
  longer generated; OpenCode phases are reached through the `/skills` picker.
  `doctor` flags and `refresh`/`cleanup-agents` remove leftovers from older
  versions.
- **`/spk-<phase>`, not `/spk.<phase>`.** Every user- and agent-facing
  reference now uses the dash form that actually matches the generated skills
  and commands — prompts, `agents-snippet.md`, `AGENTS.md`, CLI help/hints
  (`init`, `check`, `status`, `dashboard`, `archive`, `import`, `demo`,
  `explore`), the importer, and all `docs/{en,ru}`.
- **Readiness fixes.** `check-ready.*` is a no-op (`exit 0`) for auxiliary
  commands (`repo-map`, `glossary`, `challenge`, `handoff`, `recap`, `scope`,
  `rollback`, `hotfix`) instead of failing with `unknown flag: --root`. The
  managed `AGENTS.md` block and the `sdd` skill now list phases (gated) and
  auxiliary commands (not gated) separately. Readiness paths are shell-aware
  (`.sh` / `.ps1`).
- **Documentation site.** Bilingual (EN/RU) docs with search, built with
  VitePress and deployed to GitHub Pages: <https://bzdvdn.github.io/speckeep/>.
- **Release gate + tests.** `scripts/release-check.sh` (static analysis,
  `-race`, cross-platform build matrix, black-box e2e, packaging smoke), a
  golden agent-artifact matrix test across all 19 targets × 2 languages ×
  2 shells, and an upgrade-from-legacy test. CI runs `--quick` on PRs and the
  full gate on `main`/`master`.

## Upgrade

```bash
speckeep self upgrade     # or reinstall
speckeep refresh .        # heals stale agent artifacts, updates AGENTS.md
speckeep doctor .         # expect: no errors
```

If your `AGENTS.md` still uses the old `/spk.*` form, `doctor` points at it and
`refresh` rewrites the managed block.

## Workspace upgrade matrix

| From | What happens on `refresh` |
| --- | --- |
| `.claude/commands/spk.spec.md` (per-command wrappers) | removed, replaced by `spk-spec/SKILL.md` |
| `sdd/phases/*.md` (nested phases) | removed, replaced by top-level `spk-<phase>/SKILL.md` |
| `.opencode/commands/spk-*.md` | removed (OpenCode is skills-only) |
| old `/spk.` references in `AGENTS.md` | managed block rewritten to `/spk-` |
| user feature artifacts under `specs/active/` | untouched |
